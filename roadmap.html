01 the plugin Live

Five Cowork skills (streaming-setup, sync-watch-history, log-watched, top-picks, coming-soon) read Netflix and Prime Video history directly from your logged-in browser tabs via the Claude in Chrome extension, tag genre and cast through web research (neither platform exposes that metadata itself), and score candidates against a taste profile built from real, multi-year watch history.

Recommendations built from what you actually watched, not a generic trending chart.

  • JUL 2026Smarter scoring for favorite genres and actors. Broad categories like Comedy, Drama, and Documentary now count for roughly a third of a title's score. Genres you've shown you love, such as British Procedural, Spy Thriller, and Mystery, count in full, and a title earns a bonus when its cast overlaps with shows you finished and loved. This came after an early version surfaced generic trending titles, including a slapstick comedy, that didn't match your stated taste.
  • JUL 2026The full watch log is in place. Your multi-year Netflix and Prime history now comes straight from your account pages, with duplicates removed and every title tagged by genre and cast.
  • JUL 2026Coming Soon feed. Sourced from BritBox's official schedule, PBS Masterpiece, Den of Geek, and Netflix Tudum, cross-referenced against your log so continuations of shows you're already watching are prioritized.
02 the snapshot dashboard Live

A static, no-build site presenting the latest Top Picks, Taste Profile, and Coming Soon feed. No backend: Claude regenerates it from the plugin's data files and redeploys by hand.

Something to open on a phone, without opening a Cowork session first.

Every poster image now has a backup if it fails to load; before, only one of eight did. The × dismiss button's tap target grew to roughly 44px with no visible change. All 18 availability badges are now labeled for screen readers, since a hover tooltip does nothing on a touch screen. A style name the About page accidentally shared with the sitewide stylesheet was renamed to end the conflict. Pages that disagreed on the size of the watch history ("540 titles" on one, "190 titles" on another) now describe it in words instead of a number only one page kept current. Coming Soon also gained a note for when every row has been dismissed, matching the one Top Picks already had.

The site now uses the Fraunces typeface instead of Georgia, a proper-case "The Streaming Scout" wordmark with the bullet-ring mark, and gold field-note borders in place of a one-off accent color. About's numbering now matches this page's plain style instead of its own circular badge, and a banner shows when the data was last synced.
  • JUL 2026The dismiss control now works on Coming Soon too, and IMDb was added as a second source of poster art alongside Wikipedia. Real posters now appear on 10 of 12 upcoming titles, up from 3. The 2 still missing (Coastal Unit, Kill Jackie) genuinely have no published art yet on either source, so they keep an honest initials monogram rather than a fabricated image.

  • JUL 2026The site can now be added to an iPhone home screen, where it opens like an app with its own icon and no browser chrome. A new Right Now section covers in-theaters and live viewing, and the Guide and About pages were trimmed and given visuals to match the shared house style.

04 scheduled resync Live

A recurring task that reruns sync-watch-history, top-picks, and coming-soon on its own and prepares the dashboard update, instead of only refreshing when you ask. The commit is automatic; publishing it still takes one push command from Susan (the cloud session that runs this task has no GitHub network access, the same constraint as the git-connected deploy itself).

The dashboard's data stays current between visits; getting it live still takes one copy-pasted command.

  • JUL 2026A scheduled task pointed at a temporary session folder instead of stable storage. That folder wasn't reachable between runs, so years of watch history, the taste profile, and most of the exclusion list were lost. Persistent data now lives in this repo's data/ folder. The task commits changes; Susan still pushes them.
  • JUL 2026Scheduled task set up, runs Monday mornings. Each run resyncs watch history, rebuilds Top Picks and Coming Soon (honoring EXCLUDED_TITLES.md), and sources real poster art where it exists. If any step fails (login expired, a source unreachable), it stops rather than publishing a partial or guessed state.

06 a real backend In progress

A proper backend: Netlify Functions with automated backups and health checks, on a GitHub repo that auto-deploys on push. The dismiss feature was the first beneficiary: a function backed by Netlify Blobs so a dismissal syncs across devices instantly, no chat round-trip needed. Automated backups and a health check are still ahead.

Infrastructure that matches how solid the site looks, not just the look itself.

  • JUL 2026The dismiss endpoint is open to the internet by design: no login required, because a "not interested" flag isn't sensitive. It's now bounded: oversized input is rejected, and the stored list caps at 500 entries, oldest first out. That closes the obvious abuse case. Automated backups and a health check are still open.
  • JUL 2026A setback, then a fix. A working dismiss endpoint was built and deployed through the usual upload page, but it never went live. Netlify's own documentation explained why: manual uploads skip the build pipeline, and server functions only run when the site deploys from a connected Git repository. So that came first. The repo is now on GitHub, Netlify redeploys the site automatically on every push to main, and the dismiss function (netlify/functions/dismiss.mjs) shipped on that pipeline shortly after, live and backed by Netlify Blobs.
07 protect saved changes Planned

Dismissing a title is currently open to anyone with the link: no login, by design, since a "not interested" flag felt low-stakes when this shipped. As the dashboard link gets shared more, that's worth tightening: gate the dismiss endpoint's POST and DELETE behind a shared edit key (the same pattern Vinyl Scout's catalog uses), remembered in the browser after it's entered once so it doesn't cost a retype on every visit. Browsing Top Picks and Coming Soon stays open to anyone, unchanged.

A shared link lets anyone see what's recommended, not quietly reshape what's recommended.

09 a real scoring formula Planned

Every match percentage today is Claude applying the same documented weighting rules fresh each rebuild (signature genre at full weight, actor affinity as a proportional bonus, generic genre at roughly a third) and writing a number that reflects that judgment; consistent by rule, not by equation. This phase turns that into a literal, stored formula: fixed numeric weights per signature genre and per actor in TASTE_PROFILE.md, and one small scoring function that takes a title's tagged genre and cast and returns a number, the same pattern Travel Intelligence already uses for flight scoring. What stays judgment either way: deciding what genre a brand-new title even is and whether its cast really overlaps; that still comes from reading a page or a web search, not from a database. The equation only replaces the combining step, not the research step underneath it.

A score you could re-add by hand and get the same number, not just a number you have to trust.
