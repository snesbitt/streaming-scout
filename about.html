01

what it is

Ranks what to watch next from Susan's real Netflix and Prime Video history (every title since 2010, including BritBox and PBS Masterpiece), matched against her stated taste (spy, action, British procedurals; no sci-fi, fantasy, rom-coms). Also tracks premieres months ahead, and what she's watching or seeing right now.

Refreshes itself Monday mornings via a scheduled task, or sooner if Susan asks Claude to resync directly.

02

how it's scored

Every match percentage on this page comes from Claude applying three weighted signals to Susan's real watch history, freshly, each time the dashboard rebuilds. There's no stored formula behind these numbers today; there are just documented rules, followed the same way every time.

Signature genre matchfull weight
Actor affinity bonusproportional
Generic genre matchabout 1/3 weight

A genre on Susan's Signature Genres list (British Procedural, Spy Thriller, Mystery, and similar) counts in full; broad buckets like Comedy or Drama count at roughly a third; shared cast with a loved title adds a bonus on top. Loved categories boost further, hated categories force-cap negative, and anything already watched or dismissed is dropped before ranking starts.

Turning this into a literal, stored equation (the same pattern Travel Intelligence already uses for flight scoring) is on the roadmap: see Phase 09.

03

the stack

Static HTML, plus one small Netlify Function for the dismiss button. Deploys via GitHub: pushing to main triggers Netlify's Git-connected continuous deployment automatically, whether Susan pushes directly or the Monday scheduled task does.

This site, today

  • Static HTML, no build step
  • One Netlify Function: dismiss, Blobs-backed, bounded
  • GitHub repo, auto-deploy on push
  • Dismiss syncs instantly; permanent exclusion still needs a chat confirm

Where it's headed

  • Full Netlify Functions backend
  • Automated backups
  • A health check confirming each week's update published
  • Exclusions written without a chat round-trip
